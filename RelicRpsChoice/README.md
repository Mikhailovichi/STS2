# Relic RPS Choice

## 简介

`Relic RPS Choice` 是一个为《Slay the Spire 2》多人模式制作的轻量玩法 mod。

当多人宝箱房里出现共享遗物争夺时，如果多名玩家选择了同一件遗物，这个 mod 会把原本后台结算的冲突改成一个可见、可操作的石头剪刀布对决流程，由出招结果决定最终归属。

## 当前功能

- 多人宝箱房共享遗物冲突时，弹出石头 / 剪刀 / 布选择界面
- 每件发生冲突的遗物独立结算，没发生冲突的遗物仍按正常流程分配
- 支持多轮淘汰，直到决出最终赢家
- 支持鼠标点击、`1 / 2 / 3`、`R / P / S`、方向键与 `Enter / Space` 操作
- 对决期间会隐藏并拦截 `Skip` 按钮，避免误跳过导致流程异常
- 对共享遗物界面做了额外兼容处理，改善多人情况下的展示稳定性

## 安装方法

1. 完全退出游戏。
2. 将压缩包内的 `mods/RelicRpsChoice` 文件夹复制到游戏根目录下的 `mods` 文件夹中。
3. 启动游戏并确认 mod 已正常加载。

## 使用方法

1. 进入多人宝箱房的共享遗物选择流程。
2. 当多名玩家选择同一件遗物时，界面会出现石头 / 剪刀 / 布按钮。
3. 本地玩家选择出招后，系统会等待其他参与玩家完成选择并结算结果。

## 说明

- 这个 mod 主要影响多人宝箱房中的共享遗物争夺流程。
- 不会修改普通单人遗物选择。
- 不需要额外配置，安装后即可生效。
