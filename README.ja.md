# STS2 Mods

**言語 / Language / 语言**: [简体中文](./README.md) | [English](./README.en.md) | **日本語**

『Slay the Spire 2』向けの mod コレクションです。主なテーマは、マルチプレイでの連携強化、戦闘情報の可視化、そしてラン中のコミュニケーション改善です。

現在、このリポジトリには相互に補完し合う 3 つの独立した mod が含まれています。

- 🖋️ [CombatQuill](./CombatQuill): 戦闘中や関連画面で戦術的な書き込みと意思共有を行う mod
- 👀 [PartyObserver](./PartyObserver): 仲間の重要な選択情報を同期表示する mod
- 📊 [DamageMeter](./DamageMeter): 与ダメージ、リソース使用、戦闘の振り返りデータを可視化する mod

これら 3 つの mod は、単なる個別機能の追加ではありません。マルチプレイ全体に、より分かりやすい協力レイヤーを加えることを目指しています。

- `CombatQuill` は「今どう動くべきか」を伝えるためのもの
- `PartyObserver` は「仲間が今どんな選択をしているか」を把握するためのもの
- `DamageMeter` は「この戦闘で実際に何が起きたのか」を振り返るためのもの

## ✨ リポジトリの方向性

このリポジトリは、単発の実験というより、継続的に育てていくマルチプレイ支援ツール群に近い位置付けです。  
3 つの mod はすでに動作し、継続的に改善できる基盤がありますが、プロジェクト全体としてはまだ初期の公開段階にあります。方向性は明確で、UI や操作感もすでに実用レベルに達していますが、マルチプレイ同期の深さ、情報の網羅性、UI の磨き込み、長期的なデータ活用にはまだ大きな伸びしろがあります。

## 🖋️ CombatQuill

`CombatQuill` の中心にあるのは、「元の操作感を邪魔せず、マルチプレイ戦闘で本当に使いやすい書き込みレイヤーを作る」という考え方です。

マルチプレイでは、「左の敵を先に倒そう」「このカードはここに使って」「このターンは自分が守るから、そっちで締めて」といったやり取りが、音声や短いテキストに頼りがちです。  
`CombatQuill` は、そうしたその場の指示を画面上の可視化された注釈に変え、連携をより直感的にすることを目指しています。

### 機能概要

- 戦闘画面上に、必要なときだけ呼び出せる描画オーバーレイを追加し、注目点、ルート、対象、行動順を共有できます。
- 羽ペン、消しゴム、クリアなど、公式のマップ描画に近い視覚表現を採用し、ゲーム本編の雰囲気に寄せています。
- デフォルトでは通常の左クリックによるカード操作を奪わない安全寄りの入力設計になっています。
- 戦闘中に素早くオンオフできるため、重要ターンだけ一時的に使う運用にも向いています。
- 色、線の太さ、消去、透明度、ツールバー関連の基本設定がすでに用意されています。
- 実際には単なる落書き機能というより、撃破順、集中攻撃対象、保留対象、そのターンのリソース配分などを共有する軽量な戦術ホワイトボードとして機能します。

### 今後の展望

`CombatQuill` の次の大きな段階は、ローカルで便利な注釈ツールから、マルチプレイ向けの本格的な同期戦術レイヤーへ発展させることです。

- 直近では、注釈をローカル表示に留めず、仲間へより安定して共有できるよう同期面の強化が重要になります。
- 誰が描いたか、色の意味、レイヤー管理といった要素も強化し、複数人が同時に使っても読みやすい形にしていく想定です。
- 戦闘終了後の振り返りにも使えるよう、短時間の持続表示や画面遷移をまたぐ保持も自然な発展先です。
- コントローラー対応や入力カスタマイズも明確な今後の課題です。現在はキーボードとマウスの安全性を優先していますが、将来的にはパッドでも自然に使える形を目指します。
- さらに長期的には、単なる描画ツールではなく、強調マーカー、構造化された指示、簡易 ping などを含む、より広い戦術表現ツールへ進化させる余地があります。

## 👀 PartyObserver

`PartyObserver` は、「仲間が今何を見ていて、何を選ぼうとしていて、何を比較しているのか分からない」というマルチプレイ特有の悩みを、UI 上で素早く把握できる問題へ変えるための mod です。

マルチプレイでは、仲間の重要な判断がこちら側から自然には見えない場面が多くあります。  
戦闘を離れたことは分かっても、それが報酬画面なのか、イベントなのか、すでに選択完了なのかは分からないことがあります。カード報酬画面にいると分かっても、どの候補で迷っているかまでは見えないこともあります。  
`PartyObserver` は、その欠けている文脈を、簡潔で安定した低負荷の観察パネルとして補うことを目的にしています。

### 機能概要

- 対応画面上にコンパクトな仲間観察パネルを表示し、同期された仲間の状態を確認できます。
- すでにカード報酬選択やイベントルームの選択肢を同期表示できます。
- 詳細情報がまだない画面でも、仲間が現在どのマルチプレイ画面にいるかという最低限の文脈は表示できます。
- パネルは軽量かつドラッグ可能で、メイン UI を大きく邪魔せずにラン中ずっと参照できます。
- 現在の表示はシンプルですが、土台は今後の拡張を前提にしており、使い捨ての仮 UI ではありません。

### 今後の展望

`PartyObserver` は、「仲間の判断文脈をもっと自然にこちらへ持ってくる」方向で進化していきます。ただし、完全な遠隔画面ミラーを目指すわけではなく、マルチプレイ向けの状態・選択観察ツールとして育てていく想定です。

- 直近で最も分かりやすい拡張は、ショップ、焚き火、強化、削除、変化、マップ移動など、重要な場面への対応拡大です。
- 今後は単に画面種別を見せるだけでなく、「なぜここで止まっているのか」「何を比較しているのか」といった判断価値の高い文脈も重視していくはずです。
- UI も、長時間のマルチプレイに向くように、情報整理、状態フィードバック、アバター表示などの方向で改善していく余地があります。
- 同期精度が十分に安定すれば、候補要約、簡易的な意図表示、観戦しやすい簡略ビューなども将来的に追加できます。
- 長期的には、「仲間が今何をしているのか」をわざわざ聞かなくても、必要な文脈が UI に自然に現れる協力認識レイヤーを目指します。

## 📊 DamageMeter

`DamageMeter` は、単にダメージ順位を出すための mod ではありません。戦闘の中で本当に振り返る価値のあるデータを、読みやすく、比較しやすく、蓄積しやすい形にまとめることが本来の目的です。

マルチプレイでは、最終ダメージだけを見ても多くの情報が抜け落ちます。  
誰がより多くチーム支援をしたのか、誰がより多く被弾を引き受けたのか、どのターンが最大の山場だったのか、誰がエナジーを無駄にしがちなのか、その戦闘は効率が高かったのか低かったのか。  
`DamageMeter` は、そうした過程の情報まで同じ可視化レイヤーで扱えるようにするための mod です。

### 機能概要

- 戦闘中に、現在の戦闘と累積値の両方を確認できる統計パネルを提供します。
- 総ダメージ、実ダメージ、被ダメージ、ターン毎火力、チーム支援ダメージ、チーム支援ブロック、使用カード数、ブロック、エナジー、効率、オーバーキル、ポーション、デバフなど、多面的な統計をすでに扱えます。
- 単なる合計値だけでなく、チームのテンポ、ターンごとのピーク、リソース浪費の傾向を読み取れるグラフ系表示も備えています。
- 戦闘ログ、死亡記録、カードフローなど、振り返り向けの情報も表示対象に含まれます。
- 最大単発火力、単戦闘最高総量、最高ターンダメージ、最多使用カード数、最高ブロック量、累積戦闘記録など、長期記録も保持できます。
- パネル位置、スケール、透明度、表示行数などを調整でき、プレイ環境に合わせた HUD 配置が可能です。
- マルチプレイの戦闘後レビューだけでなく、ソロでビルドの実力を検証したいときにも役立ちます。

### 今後の展望

`DamageMeter` の次の焦点は、「さらに数字を増やすこと」ではなく、「数字の意味をもっと読み取りやすくすること」です。比較しやすく、長期分析に耐える情報へ育てていくことが重要になります。

- 直近では、カテゴリ表示の可読性向上、グラフ表現、行数制御、重要データの強調、戦闘テンポ差への安定対応が主な改善点になります。
- 将来的には、ダメージ、ブロック、リソース獲得をカード、レリック、パワー、ターン区間などへ細かく分解し、何が本当に効いているのかを見やすくする方向が有力です。
- 現在の戦闘単位の集計から、部屋、エリート、ボス、キャラクター、あるいは run 全体の比較へ広げることも自然な拡張です。
- グラフ機能がさらに成熟すれば、火力の立ち上がり、リソース枯渇、瞬間火力ターンをより直感的に捉えられるトレンド表示も強化できます。
- 長期的には、局内 HUD を超えて、「結果がどうだったか」だけでなく「なぜそうなったのか」まで支援できる分析ツールへ育てていく余地があります。

## 🛠️ ローカルビルド

- 現在のプロジェクトファイルは、このリポジトリがゲームの `modding/` ディレクトリ配下にあることを前提にしています。
- `build-combatquill.ps1` は `CombatQuill` のビルドまたは publish に使います。
- `build-partyobserver.ps1` は `PartyObserver` のビルドまたは publish に使います。
- `DamageMeter/build.ps1` は `DamageMeter` をビルドし、必要に応じてローカルの `mods/` ディレクトリへインストールできます。
- `CombatQuill` と `PartyObserver` はリポジトリ内のローカルツールチェーンでビルドし、`DamageMeter` はシステムの `dotnet` を利用してビルドします。

## 🚧 現在の状態

3 つの mod はいずれも、公開しながら継続的に改善していける段階にありますが、プロジェクト全体としてはまだ初期段階です。  
今後の魅力は単一の機能追加よりも、次の 3 つが徐々に組み合わさって、より完成度の高いマルチプレイ支援体験になっていく点にあります。

- より自然な戦術書き込み
- より分かりやすい仲間状態の把握
- より深い戦闘とビルドの振り返り

この統合的な方向性こそが、このリポジトリの長期的な主軸です。
